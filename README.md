# Awesome Free Browser Dev Tools

A curated list of **free developer tools that run in your browser**. Every tool here works without installing anything, and the core features work without creating an account.

Useful when you're on a locked-down work laptop, a Chromebook, someone else's computer, or you just want a quick answer without setting up a project.

> **Criteria:** free to use, runs in the browser, no signup needed for the main features. Suggestions welcome, see [Contributing](#contributing).

## HTML, CSS & JavaScript playgrounds

- [CodePen](https://codepen.io) - Front-end playground with a huge community of examples.
- [JSFiddle](https://jsfiddle.net) - Classic playground for testing HTML, CSS and JS snippets.
- [HTML Suite: HTML Editor](https://htmlsuite.com) - HTML, CSS and JS editor with live preview, console output and download, no signup.
- [HTML Suite: HTML Viewer](https://htmlsuite.com/html-viewer) - Paste or open an HTML file and see it rendered.

## Run Python in the browser

- [Pyodide REPL](https://pyodide.org/en/stable/console.html) - Official Python console running on WebAssembly.
- [HTML Suite: Python Online Compiler](https://htmlsuite.com/python-online-compiler) - Python 3 in the browser with interactive `input()`, code never leaves your device.

## Formatters & minifiers

- [Prettier Playground](https://prettier.io/playground/) - Try Prettier formatting for JS, TS, CSS, HTML, Markdown and more.
- [HTML Suite: HTML Formatter](https://htmlsuite.com/html-formatter) / [HTML Minifier](https://htmlsuite.com/html-minifier) - Beautify or minify HTML.
- [HTML Suite: SQL Formatter](https://htmlsuite.com/sql-formatter) - Format SQL queries.

## JSON, YAML, XML & CSV

- [BestJSON](https://bestjson.com/) - Format, validate, repair, compare, and convert JSON locally in the browser without an account.
- [JSON Crack](https://jsoncrack.com/editor) - Visualize JSON, YAML, CSV and XML as interactive graphs.
- [HTML Suite: JSON Formatter](https://htmlsuite.com/json-formatter) - Pretty-print JSON with exact error locations.
- [HTML Suite: YAML Formatter](https://htmlsuite.com/yaml-formatter) - Format and validate YAML.
- [HTML Suite: CSV to JSON](https://htmlsuite.com/csv-to-json) - Convert CSV to JSON and back.

## Regex

- [regex101](https://regex101.com) - Regex tester with explanations, debugger and multiple flavors.
- [RegExr](https://regexr.com) - Learn, build and test regular expressions.

## Encoding, decoding & tokens

- [CyberChef](https://gchq.github.io/CyberChef/) - The "Cyber Swiss Army Knife": encoding, hashing, compression and hundreds of other operations.
- [jwt.io](https://jwt.io) - Decode and inspect JSON Web Tokens.
- [HTML Suite: Base64 Encode](https://htmlsuite.com/base64-encode) / [URL Encode](https://htmlsuite.com/url-encode) - Quick encoders and decoders.

## Diff & text

- [HTML Suite: Diff Checker](https://htmlsuite.com/diff-checker) - Compare two texts side by side.
- [HTML Suite: Word to HTML](https://htmlsuite.com/word-to-html) - Paste from Word or Google Docs and get clean HTML.

## Colors & accessibility

- [Coolors](https://coolors.co) - Fast color palette generator.
- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) - Check WCAG color contrast.
- [HTML Suite: Image Color Picker](https://htmlsuite.com/image-color-picker) - Pick HEX/RGB colors from an image, processed locally.

## Images & SVG

- [Squoosh](https://squoosh.app) - Compress and convert images in the browser.
- [SVGOMG](https://jakearchibald.github.io/svgomg/) - Optimize SVG files with a visual UI for SVGO.

## Markdown & documents

- [StackEdit](https://stackedit.io/app) - Full-featured in-browser Markdown editor.
- [HTML Suite: Markdown Editor](https://htmlsuite.com/markdown-editor) - Write Markdown with live preview.
- [HTML Suite: PDF Editor](https://htmlsuite.com/pdf-editor) - Edit PDF files in the browser.

## Diagrams & whiteboards

- [Excalidraw](https://excalidraw.com) - Hand-drawn style whiteboard and diagrams.
- [tldraw](https://www.tldraw.com) - Simple, fast infinite canvas.
- [Mermaid Live Editor](https://mermaid.live) - Create diagrams from text.

## Misc

- [crontab.guru](https://crontab.guru) - Understand and write cron expressions.
- [HTML Suite: Unix Timestamp Converter](https://htmlsuite.com/unix-timestamp-converter) - Convert timestamps to dates and back.
- [HTML Suite: UUID Generator](https://htmlsuite.com/uuid-generator) - Generate UUIDs.

## Contributing

Know a great free browser tool? Open an issue or a pull request. Please make sure it:

1. is free to use,
2. runs in the browser,
3. doesn't require an account for its main features.
